Privacy and security

Last updated August 24, 2026.

Analytics

The site uses privacy-conscious traffic and download measurement to understand readership, publication use, and site reliability.

Security and document delivery

Norynthe.Pulse and Cloudflare may record the requested page or document, time, request method, response outcome, referrer, user agent and client-hint fields, language preference, Cloudflare request identifier and edge location, approximate location, network number and organization, connection protocol and security metadata, and bot-detection signals. These records are used to deliver documents, enforce crawler preferences, investigate abuse, and distinguish automated traffic from human activity.

A keyed one-way representation of the source IP address may be retained for event correlation. The full source IP address is encrypted and normally retained for no more than 14 days for security investigation, then deleted unless a specific incident requires a limited, documented preservation period. Full addresses are not used for advertising or displayed in ordinary analytics views.

Automated access

The site permits search and user-directed retrieval agents but does not permit automated collection for model training where identified by supported crawler controls.
